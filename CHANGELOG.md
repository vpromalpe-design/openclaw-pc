# Changelog

OpenClaw PC — Windows-приложение и установщик для OpenClaw: агенты, модели, голос и Telegram в одном месте.

> **Политика публикаций (с 0.9.0):** все сборки до релизной версии **не публикуются** — это внутренние этапы разработки. Опубликован будет только **v1.0.0** и последующие версии. Ниже — полная карта истории проекта.

---

Первый публичный релиз.

## v0.9.24 — Рассинхрон моделей устранён + чистый композер (2026-09-01, по баг-репорту Дамира)

Три пункта из отчёта по текущей сборке:

- **1. DeepSeek больше не становится основным автоматически** — при сохранении провайдера (`saveProviderConfig`) убран авто-назначение primary «первой настроенной модели». Провайдер просто добавляется в allowlist и находится «наряду со всеми»; основная модель меняется только явно (визард или кнопка «Подключить» в «Моделях»).
- **2. Единый источник истины — модель активного агента** (`agents.list[].model ?? дефолт`):
  - панель «Состояние» и статусбар раньше показывали только глобальную primary → теперь показывают модель **активного** агента (совпадает с меню агента);
  - «Подключить» в «Моделях» (`applyModelsPriority`) теперь синхронизирует **allowlist** (`agents.defaults.models`) для primary+fallbacks — раньше gateway отклонял выбранную модель вне allowlist, кнопка «нажата, но не работает», фактически оставалась старая модель;
  - меню модели агента подгружает свежий список моделей при **каждом открытии** (не только при старте/refresh) — подключённые модели появляются сразу;
  - после любого действия в «Моделях» (подключить/сохранить/добавить/fetch) шелл обновляется немедленно через `onChanged → refreshShellData`;
  - при выборе модели в меню агента сайдбар/«Состояние» обновляются оптимистично, без ожидания перечитывания конфига.
- **3. Внизу у поля ввода убраны все кнопки и настройки** (CSS-инъекция в Control UI): скрыты селектор модели (`chat-composer-model-control`), скрепка прикрепления (`agent-chat__attach-menu`), чип настроек (`chat-settings-chip`) и model-bar. Остались только поле ввода и кнопка отправки. Выбор модели — только в меню самого агента.
- **4. Голосовой ввод в чате — один микрофон с тумблером Офлайн/Онлайн** (вместо нативной realtime-кнопки Control UI, падавшей «Realtime voice provider is not configured»):
  - кнопка 🎤 у поля ввода + капсула-тумблер; **Офлайн** = запись с микрофона → whisper.cpp (локально, без интернета и ключей), распознанный текст вставляется в поле ввода; **Онлайн** = нативный realtime-talk (если провайдер и ключ настроены в Голос → Онлайн-распознавание);
  - если выбранный способ не настроен — понятная подсказка и предложение другого способа, никаких сырых ошибок ядра;
  - «Голос» → «Распознавание речи»: селектор способа по умолчанию (Авто / Локально / Облако), сохраняется в конфиг оболочки (`sttPreferredMode`) и применяется микрофоном в чате;
  - реализация: патч Control UI (`scripts/lib/patch-openclaw-ui-voice-input.ts`, Lit-компонент `openclaw-pc-voice-input`), мост `openclaw-pc:stt` (шело-сторона в `App.tsx`), IPC `stt:setPreferredMode`.

Проверено: type-check ✅ lint ✅ build ✅.

## v0.9.23 — Модели = мастер (A+B+C по решению Дамира, 2026-09-01)

Страница **«Модели»** после мастера теперь позволяет **абсолютно всё**, что делает мастер настройки — добавление/изменение провайдеров, моделей и ключей:

- **(A) Единый каталог провайдеров** — `src/shared/provider-catalog.ts`: человеческие имена (DeepSeek, OpenRouter, …), endpoint-дефолты и алиасы для всех провайдеров; используется и в main, и в renderer (без дублирования).
- **(A) Сохранение провайдера синхронизирует allowlist** — любая сохранённая модель автоматически дописывается в `agents.defaults.models` (+ primary для первой) и сразу видна в селекторах и меню агентов. Исправлен баг «модель не видна после сохранения».
- **(A) Человеческие имена в таблице** — `deepseek-direct` показывается как «DeepSeek»; дубль-строка канонического `deepseek` скрывается, когда есть `deepseek-direct`.
- **(C) Пикер моделей = merge** — RPC `models.list` + конфиг (`models.providers` + allowlist), dedupe по `provider/id`: видны ВСЕ модели, включая локальные.
- **(B) «Загрузить модели»** — кнопка в панели провайдера и в форме добавления: GET `/models` с API провайдера (Bearer / `x-api-key`+`anthropic-version`, спец-обработка Ollama `/api/tags` и Google `?key=`), результат — готовый список в селекторе модели.
- **(B) Панель провайдера = полный аналог мастера** — API base URL для любого провайдера (префилл из каталога), совместимость для custom, регион Moonshot, Account/Gateway ID для Cloudflare.
- **(B) Секция «Добавить провайдера»** — провайдер + модель + ключ + endpoint + «Проверить» + «Добавить» (мастер-аналог прямо на странице «Модели»).
- **(B) Меню модели агента** — группы «Облачные» / «Локальные», человеческие имена; выбор `local/<model>` реально запускает локальный движок (`localEngineStart`).
- Расширены пресеты моделей (openrouter, mistral, groq, cerebras, huggingface, venice, together, nvidia); локали ru/en/zh.

## v0.9.0 — середина разработки: свежий старт

**Опорная сборка.** От этой версии проект считается «как с нуля»:

- **Навигация заново:** слева 4 главных раздела — **Чат · Модели · Телеграм · Голос**; остальное убрано в меню **⋯** («Разделы»: Обзор, Активность, Сеансы, Задания Cron, Задачи, Навыки) и служебные пункты (Журналы, Статистика, Резервная копия, Обновления, О приложении).
- **Единый набор иконок** — все пункты меню на lucide-иконках (без эмодзи-разнобоя).
- **Полная чистка бренда и кода:**
  - удалены все следы старых названий и «стеклянного» брендинга в коде и интерфейсе;
  - **Feishu удалён полностью** (UI, трей, IPC, pairing-модуль, локали, документация) — приложение не содержит его следов;
  - оставлены **3 языка интерфейса**: Русский · English · 简体中文 (как в установщике);
  - удалены мёртвые следы отменённой светлой темы — **тёмная тема теперь единственная**;
  - git-история переписана в один свежий коммит; старые теги и релизы удалены.
- **Новая нумерация:** история проекта от первой публикации распределена по этапам 0.1.0–0.9.0 (ниже), дальше — как есть, до релиза **v1.0.0**.
